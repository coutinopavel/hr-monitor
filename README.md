La app de monitoreo de frecuencia cardiaca detecta tu frecuencia cardiaca en línea a través de un sensor con pletismografía de luz infrarroja y luz roja.

Los componentes del proyecto son:

-Max30102
-Microcontrolador Seeed xiao nrf52840
-Celular con android
-Computadora para enviar APK al celular

Para poder correr este proyecto......

#Descargar el hr_arduino.ino y moverlo a una carpeta externa del repo.
Esto se debe realizar ya que al momento de correrlo en el IDE de Arduino, la dirección del repositorio interfiere con la del documento y el IDE Arduino no logra encontrar el documento. Simplemente mover a una carpeta anterior a donde se guardó el repositorio y debería correr sin problemas.

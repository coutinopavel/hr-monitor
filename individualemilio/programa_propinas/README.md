# Tip & Split

App Flutter de una sola pagina para calcular propina y dividir la cuenta.

Funciones principales:
- Campo para ingresar el total de la cuenta (solo numeros).
- Slider para elegir porcentaje de propina de 0% a 30%.
- Control de personas con botones + y - (minimo 1).
- Resultados con propina total, total general y pago por persona destacado.

Diseno:
- Uso de Cards con bordes redondeados.
- Bloque de total por persona con fondo color deepPurple.
- SafeArea para evitar colisiones con el notch.
